# 🎓 Predict Students' Dropout and Academic Success

Este proyecto implementa un pipeline completo de Ciencia de Datos para predecir el abandono escolar y el éxito académico de los estudiantes. Es un caso real de análisis predictivo diseñado para ayudar a las instituciones educativas a identificar estudiantes en riesgo de forma temprana.

---

## 🚀 Resumen del Proyecto
El objetivo es clasificar a los estudiantes en tres categorías: **Dropout** (Abandono), **Enrolled** (Matriculado) o **Graduate** (Graduado). Para ello, analizamos variables sociodemográficas, económicas y el rendimiento académico previo.

### Key Highlights:
- **Pipeline:** Ingesta de datos -> Limpieza -> EDA -> Modelado -> Dashboard.
- **Stack:** Python (Pandas, Scikit-learn, Seaborn), SQL, Power BI.
- **Arquitectura:** Siguiendo principios de código limpio y escalable (Playbook Architecture).
