# Project: Predict Students' Dropout and Academic Success

This project will guide a beginner data analyst through a complete data science pipeline, from problem definition to Power BI dashboard development.

## Pipeline Tasks

- [ ] 1. Problem definition & Data ingestion
- [ ] 2. SQL data exploration
- [ ] 3. Data cleaning (Python)
- [ ] 4. Exploratory Data Analysis (EDA)
- [ ] 5. Feature engineering
- [ ] 6. Model training
- [ ] 7. Model evaluation
- [ ] 8. Dashboard development (Power BI)
- [ ] 9. Documentation and report
